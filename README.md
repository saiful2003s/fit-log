# FitLog

FitLog is a dark-themed workout management web application that helps users explore exercises, create a personal workout plan, save exercises, and track completed workouts.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- REST API

## Key Features

1. **Workout Library**
   - Browse a collection of exercises with information such as muscle groups, equipment, duration, calories, and rating.

2. **Workout Details**
   - View detailed information about each exercise, including description, difficulty, sets, reps, and step-by-step instructions.

3. **Personal Workout Plan**
   - Add exercises to a personal plan and mark exercises as completed.

4. **Save Exercises**
   - Save favorite exercises and access them from the My Plan page.

5. **Workout Tracking**
   - Track the number of exercises, total workout duration, and total calories, with sorting options by duration, calories, and rating.
